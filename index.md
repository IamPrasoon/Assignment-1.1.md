When we type a URL in a browser like Chrome, the browser (client) sends an HTTP or HTTPS request to a web server. HTTP stands for HyperText Transfer Protocol, and HTTPS stands for HyperText Transfer Protocol Secure. The server processes the request, gets data from a database if needed, and sends a response back to the browser. The browser displays the website using HTML, CSS, and JavaScript. This process is called the request-response cycle. A static website shows mostly fixed content, while a dynamic website displays content that can change based on users or data.
